# 📊 Трансформація табличних даних з Google Sheets

## 📋 Опис завдання

Цей проект реалізує скрипт для автоматичної трансформації даних з Google Sheets. Скрипт читає дані з публічної Google таблиці та трансформує їх згідно зі спеціальною логікою розширення рядків.

### Логіка трансформації

Вхідні дані містять колонки:
- **Дата** - дата запису
- **Область** - назва області
- **Місто** - назва міста
- **Значення 1 - Значення 10** - числові значення
- **long** - довгота
- **lat** - широта

#### Приклад 1: Рівні значення
Якщо `Значення 1 = 3` і `Значення 2 = 3`:
- Створюється **3 рядки**
- У кожному рядку `Значення 1 = 1` і `Значення 2 = 1`
- Решта колонок `Значення 3-10 = 0`
- Базові поля (Дата, Область, Місто, long, lat) дублюються в кожному рядку

#### Приклад 2: Різні значення
Якщо `Значення 1 = 5` і `Значення 2 = 3`:
- Створюється **5 рядків** (за максимальним значенням)
- В перших 3 рядках: `Значення 1 = 1`, `Значення 2 = 1`
- В рядках 4-5: `Значення 1 = 1`, `Значення 2 = 0`
- Решта колонок `Значення 3-10 = 0`

### Завантаження даних в ArcGIS Online

Після трансформації даних ви можете завантажити їх в ArcGIS Online Feature Layer:

```bash
python upload_to_arcgis.py
```

#### Налаштування для ArcGIS Online

1. **Отримайте Item ID вашого Feature Layer:**
   - Відкрийте ваш Feature Layer в ArcGIS Online
   - Item ID знаходиться в URL: `https://www.arcgis.com/home/item.html?id=[ITEM_ID]`

2. **Додайте Item ID в .env файл:**
   ```env
   ARCGIS_ITEM_ID=your_item_id_here
   ```

3. **Переконайтеся, що Feature Layer є публічним:**
   - Скрипт використовує анонімне підключення `GIS()` без автентифікації
   - Feature Layer повинен мати публічний доступ для читання та редагування

#### Що робить скрипт upload_to_arcgis.py:

- ✅ Читає `ARCGIS_ITEM_ID` з `.env` файлу
- ✅ Підключається анонімно до ArcGIS Online (без автентифікації)
- ✅ Завантажує дані з `data/transformed_data.csv`
- ✅ Виконує маппінг полів CSV → ArcGIS:
  - `Дата` → `d_date`
  - `Область` → `t_region`
  - `Місто` → `t_city`
  - `Значення 1-10` → `i_value_1` - `i_value_10`
  - `long` → `long`
  - `lat` → `lat`
- ✅ Створює features з геометрією Point (WGS84 координати)
- ✅ Завантажує дані пакетами по 100 записів
- ✅ Логує весь процес та виводить підсумки

## 💻 Технічні деталі реалізації

### Клас DataTransformer

Основний клас для трансформації даних містить наступні методи:

#### `read_google_sheet()`
Читає дані з публічної Google таблиці через CSV export URL.

```python
transformer = DataTransformer(spreadsheet_id)
df = transformer.read_google_sheet()
```

#### `transform_row(row)`
Трансформує один рядок згідно з бізнес-логікою:
1. Знаходить максимальне значення серед Значення 1-10
2. Створює відповідну кількість рядків
3. Заповнює значення: 1 якщо оригінальне значення >= номер рядка, інакше 0

#### `transform_data()`
Трансформує весь DataFrame з відображенням прогресу:
- Обробляє дані партіями
- Виводить прогрес кожні 50 рядків
- Оптимізовано для роботи з великими обсягами даних

#### `save_to_csv(df, output_path)`
Зберігає результат у CSV файл з UTF-8 кодуванням:
- Автоматично створює директорію output/
- Виводить розмір збереженого файлу
- Використовує UTF-8-SIG для коректного відображення кирилиці
